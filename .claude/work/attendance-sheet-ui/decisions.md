## U10-B 확정 내용
- 형식: `{일}日（{요일}）` — 일은 앞자리 0 없음, 괄호는 전각 `（` `）`(U+FF08/U+FF09), 월 없음. 예: `1日（日）`, `14日（土）`.
- 변경 범위: md 이상 出勤簿 月間表의 日付 열 표시와, 같은 함수를 쓰는 時間帯 막대의 접근 가능한 이름 앞 날짜(U1 보완, `2日（月） 09:00〜18:00 勤務…`)만.
- 바꾸지 않는 것: 退勤時刻의 자정 넘김 표기(`formatClockOut`, `2026/11/05 02:00`), 월 라벨(`2026年11月`), 현재 일시 카드, LeaveDetailModal 등 모달의 날짜, md 미만 `AttendanceHistoryView`(`formatWorkDate` `2026/11/07(土)`), 관리자 화면. 이 표기들은 `formatSheetDate`를 쓰지 않으므로 함수 변경만으로 영향 없음.
- 구현 위치: 기존 `lib/attendance-sheet.ts` `formatSheetDate(ymd)`의 출력만 변경(사용처는 `AttendanceSheetView.tsx` 1곳뿐). 새 함수·`lib/format.ts` 변경 없음. 요일은 기존 `messages.calendar.weekdays` 재사용.

## U1-A 보완(구현 규칙)
- 행 선택(클릭·Enter/Space, `aria-selected`, `tabIndex`)은 왼쪽 행이 담당. 오른쪽 행은 클릭 시 같은 날짜를 선택(포커스 대상 아님), 배경(선택·퇴근 누락·회색)은 양쪽 동일.
- 오른쪽 스크롤 영역은 `role="region"` + `aria-label="時間帯"` + `tabIndex={0}`(키보드로 가로 스크롤 가능).
- 오른쪽 막대의 접근 가능한 이름 앞에 날짜를 붙인다(예: `2日（月） 09:00〜18:00 勤務、…`, U10-B 형식) — 표가 나뉘어 행 맥락이 없어지므로.
