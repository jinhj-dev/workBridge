# SCR-003: 출근부

## 1. 기본 정보

| 항목 | 내용 |
|---|---|
| Screen ID | SCR-003 |
| 화면명 | 출근부 (메뉴·페이지 제목·메타 title: `出勤簿`) |
| URL | /attendance (md 이상 `?month=YYYY-MM` / md 미만 `?startDate=&endDate=&status=&page=`) |
| 접근 권한 | 공통 |
| 관련 요구사항 | FR-ATT-006(md 이상), FR-ATT-003(md 미만) |

## 2. 화면 목적

로그인한 사용자가 본인의 근태를 월 단위 출근부로 조회한다. 조회 전용이며 출근·퇴근 버튼은 두지 않는다. 화면 폭이 md(768px) 미만이면 출근부 대신 기간별 근태 이력 목록을 표시한다(§9).

## 3. 화면 구성

화면 폭에 따라 다음 중 하나만 표시한다.

| 폭 | 표시 |
|---|---|
| 판정 전(서버 렌더·hydration 직후) | 로딩 스피너(`role="status"`, 페이지 로딩 표시와 같음). API 호출 없음 |
| md(768px) 이상 | 출근부(아래 구성, §4·§5) |
| md 미만 | 근태 이력 목록(§9) |

- 두 화면을 동시에 렌더링하지 않는다(CSS 숨김 병행 금지). 선택된 화면의 API만 호출한다.
- 회전·리사이즈로 경계를 넘으면 즉시 다른 화면으로 바뀐다. URL Query는 변환·정리하지 않고 각 화면이 자기 키만 해석한다(출근부 `month`, 목록 `startDate`·`endDate`·`status`·`page`). 화면 안의 상태(선택 행, 열린 모달, 입력 중인 기간)는 초기화된다.

md 이상(출근부)은 위에서 아래로 다음 순서로 배치한다.

| 영역 | 설명 |
|---|---|
| Page Header | h1 `出勤簿` + 조회 월 라벨(예: `2026年11月`) + [前月][翌月] 아이콘 버튼 + [今月] 버튼(이번 달이면 disabled) |
| 현재 일시 카드 | Asia/Tokyo 기준 연도(`2026年`)·날짜(`11月10日(火)`)와 큰 시각(`09:14`). 분 경계에 맞춰 1분마다 갱신. 출근·퇴근 버튼 없음 |
| 月間表(Card `出勤簿`) | 그 달 1일~말일 전 일자 표. 표 위에 범례(勤務·休憩(計算値) 색 견본) |
| 月間集計(Card `月間集計`) | 정의 목록 그리드(`sm` 2열, `lg` 4열) |

- 조회 월은 URL Query `month`에 유지한다. 없거나 형식이 틀리면 이번 달로 표시한다. 월 이동 중에는 이전 표·집계를 흐리게(`opacity-60`, `aria-busy`) 남긴다.
- 화면을 연 채 날짜가 바뀌면 오늘 강조·[今月] disabled·기본 월이 새 날짜를 따른다.

## 4. 月間表

열: 日付 / 勤務パターン / 出勤時刻 / 退勤時刻 / 休憩時間 / 実働時間 / 備考 / 申請 / 時間帯

| 열 | 표시 |
|---|---|
| 日付 | `2日（月）` 형식(월 없음, 앞자리 0 없음, 전각 괄호). 토요일 파란 글자(`primary-100`), 일요일·공휴일 빨간 글자(`danger-100`). 오늘은 Bold + `aria-current="date"` |
| 勤務パターン | 우선순위: 승인된 종일 휴가 → 휴가 종류명 > 공휴일 → `祝日` > 토·일 → `休日` > `通常`. Pill 배지(`Badge shape="pill"`)로 표시하며 색은 `通常` neutral / `休日`·`祝日` danger / 휴가 success |
| 出勤時刻 | 출근 시각. 기록 없으면 빈칸 |
| 退勤時刻 | 퇴근 시각(자정을 넘기면 날짜 포함). 근무 중·퇴근 누락은 상태 배지. 퇴근 누락 배지는 「管理者に退勤時刻の修正を依頼してください。」 툴팁(기존 문구) |
| 休憩時間 | 퇴근 완료 행만. 법정 최저 휴게 계산값 + 보조 라벨 `計算値`. 헤더의 `休憩時間`에 툴팁 「実際の休憩記録はありません。労働基準法の最低休憩時間から計算した値です。」(행마다 두지 않음) |
| 実働時間 | 퇴근 완료 행만. 拘束 − 휴게 |
| 備考 | 공휴일명 + 관리자 수정 기록이면 `管理者修正`. 둘 다면 `文化の日・管理者修正`처럼 `・`로 연결 |
| 申請 | 그날을 포함하는 본인 휴가(신청 중·승인)를 `休暇 {상태}`(예 `休暇 承認済み`) 배지 버튼으로 표시. 휴가 종류명은 勤務パターン에만 표시한다. 클릭 시 휴가 상세 모달(LeaveDetailModal). 모달에서 처리하면 표·집계를 다시 조회 |
| 時間帯 | 0~24시 막대(2시간 눈금). 퇴근 완료 행은 근무 구간과 휴게 구간, 근무 중·퇴근 누락 행은 출근 위치에 점만 표시. 24시 초과 부분은 잘라냄. 기록 없는 날은 눈금만 |

- 공휴일 여부는 API의 `dayType`·`holidayName`만 사용한다(화면에서 판정하지 않음).
- 데이터 없는 날도 같은 행 높이를 유지하고 빈 칸은 빈 문자열로 둔다.
- 행 배경 우선순위: 선택(`bg-primary-30`) > 퇴근 누락 강조 > 회색(토·일·공휴일, 승인된 종일 휴가) > 흰색. 승인된 반차는 흰색 배경 + 申請 배지만.
- 평일 공휴일에 휴가가 있으면 배지를 그대로 표시한다(휴가 일수 규칙상 차감됨, FR-ATT-006 공휴일 취급 불일치).
- 행 선택: 행 클릭 또는 Enter/Space(행에 포커스 가능). 초기 선택은 오늘(그 달에 있을 때). 선택은 표시 전용이며 URL에 반영하지 않는다.
- 표는 좌우 2개로 나눈다. 왼쪽(日付~申請 8열, 표 이름 `出勤簿`)은 스크롤하지 않고, 오른쪽 時間帯 영역(`role="region"`, 이름 `時間帯`, 최소 480px)만 폭이 부족할 때 가로 스크롤한다. 두 영역 사이에 진한 회색 세로 구분선(2px `general-60`)을 둔다. 두 표는 같은 행 높이(헤더 44, 행 36)로 행이 맞춰지며, 세로는 페이지 스크롤로 함께 움직인다. 왼쪽 셀은 줄바꿈하지 않는다. 폭이 충분하면 스크롤 없이 본문 폭을 모두 쓴다.
- 오른쪽 행 클릭도 같은 날을 선택한다(키보드 선택은 왼쪽 행만). 時間帯 막대의 접근성 이름에는 날짜를 앞에 붙인다(예 `2日（月） 09:00〜18:00 勤務…`). 時間帯 영역은 실제로 넘쳐 스크롤할 수 있을 때만 키보드 포커스 대상(`tabIndex=0`)이 된다.
- 왼쪽 영역도 들어가지 않을 만큼 좁으면 두 영역 전체를 감싼 바깥 래퍼가 가로 스크롤한다(안전망, 日付 열 sticky). 사이드바가 있는 1024px 부근에서는 왼쪽 8열이 본문 폭 대부분을 차지해 그래프가 처음엔 거의 보이지 않으며, 바깥 래퍼를 가로 스크롤한 뒤 그래프 영역을 다시 스크롤하는 2단 스크롤이 된다. md 미만은 §9.

## 5. 月間集計

| 항목 | 설명 |
|---|---|
| 所定労働日数 | 입사일 이후의 공휴일 제외 평일 수 |
| 実労働日数 | 퇴근 완료한 날 수 |
| 実労働時間 | 実働 합계 |
| 時間外労働時間 | 평일 1일 実働 8시간 초과분 합계 |
| 深夜労働時間 | 22:00~05:00 근무(휴게 제외) 합계 |
| 休日労働時間(土日・祝日) | 토·일·공휴일 実働 합계 |
| 有給休暇取得日数 | 승인된 연차 1일·반차 0.5일 합계 |
| `{year}年 有給残日数` | 조회 월 연도의 잔여 연차(API-LEAVE-006). 조회 실패 시 그 항목만 `—` |

- 값은 모두 API 집계값을 그대로 표시한다. 所定労働時間·欠勤日数는 표시하지 않는다.

## 6. API

- `GET /api/v1/attendance/monthly?month=YYYY-MM` (API-ATT-007)
- `GET /api/v1/leaves/balance?year=YYYY` (API-LEAVE-006, 잔여 연차)
- 휴가 상세 모달: API-LEAVE-004 등(LeaveDetailModal)
- md 미만: `GET /api/v1/attendance?startDate=&endDate=&status=&page=&limit=20` (API-ATT-004)

조회 대상은 서버에서 로그인한 사용자 본인으로 제한한다.

## 7. 상태 처리

공통 규칙(03 Common UI Rules)을 따른다.

- Loading: 표는 Skeleton 줄, 집계는 Skeleton
- Error: 표·집계 각각 SectionError(다시 시도)
- 400 VALIDATION_ERROR: URL 해석 단계에서 이번 달로 대체하므로 정상 흐름에서는 발생하지 않는다.

## 8. 완료 조건

- 본인의 근태만 월 단위로 조회할 수 있다.
- 월 이동과 조회 월의 URL Query 유지가 정상 작동한다.
- 토·일·공휴일, 승인된 종일 휴가 행이 구분되어 표시된다.
- 휴게는 계산값임이 표시되고 実働·집계가 API 값과 일치한다.
- 퇴근 누락 기록이 구분되어 표시된다.
- md 미만에서는 §9의 근태 이력 목록만 표시되고, 경계를 넘으면 다른 화면으로 바뀐다.

## 9. 좁은 폭(md 미만) 표시

출근부 도입 전의 SCR-003 근태 이력 화면을 md 미만 전용으로 복원한 것이다(출근부 도입 시 삭제했던 상태 필터·기간 검색·페이지네이션·카드 목록 명세의 복원). 제목·메뉴는 폭과 관계없이 `出勤簿`이다.

| 영역 | 설명 |
|---|---|
| Page Header | h1 `出勤簿` |
| 검색 조건(Card `検索条件`) | 기간(시작일·종료일, DateRangeFields) + 상태 토글 버튼(`勤務中`·`退勤済み`·`退勤漏れ`, 복수 선택, StatusFilterButtons) + [照会] 버튼. 안내 「選択しない場合はすべての状態を表示します。」 |
| 목록(Card `勤怠一覧`) | 카드 목록(근무일 내림차순, 20건) + Pagination |

- 조회 조건과 페이지는 URL Query(`startDate`·`endDate`·`status`(쉼표 구분)·`page`)에 유지한다(03 목록 규칙). 없거나 틀린 값은 기본값(이번 달 1일 ~ 오늘, Asia/Tokyo, 상태 전체, 1페이지)으로 대체한다.
- 기간은 [照会]를 눌렀을 때 반영하고 1페이지로 이동한다. 기간 오류(미입력, 시작일 > 종료일, 1년 초과)는 기간 필드 아래에 표시하고 목록을 표시하지 않는다. 서버의 400 `INVALID_DATE_RANGE`도 같은 위치에 표시한다.
- 상태 버튼은 누른 시점에 반영한다(URL의 기간 그대로 1페이지, 스크롤 위치 유지). 결과가 올 때까지 이전 목록을 흐리게(`opacity-60`, `aria-busy`) 남긴다.
- 카드 한 건: 근무일 + 상태 배지 / `出勤 HH:mm / 退勤 HH:mm / 勤務時間 H:mm`(자정을 넘긴 퇴근은 날짜 포함) / 관리자 수정 기록이면 `備考: 管理者修正` / 퇴근 누락이면 강조 배경 + 「管理者に退勤時刻の修正を依頼してください。」를 직접 표시.
- 근무 시간은 API-ATT-004의 `workMinutes`(拘束)이며 휴게를 빼지 않는다.
- Empty: 상태 미선택 「照会期間に勤怠記録がありません。」, 상태 선택 「条件に一致する勤怠記録がありません。」. 범위 밖 페이지라 0건이어도 전체 건수가 있으면 Pagination을 표시한다.
- Loading: Skeleton 줄. Error: SectionError(다시 시도).
- 목록 컴포넌트에는 md 이상용 표 분기가 남아 있으나 md 미만에서만 마운트되므로 표시되지 않는다.
