# SCR-006: 사원 관리

## 1. 기본 정보

| 항목 | 내용 |
|---|---|
| Screen ID | SCR-006 |
| 화면명 | 사원 관리 |
| URL | /admin/users |
| 접근 권한 | 관리자 |
| 관련 요구사항 | FR-USER-001 |

## 2. 화면 목적

관리자가 시스템에 등록된 사원을 조회하고 신규 사원을 등록한다.

## 3. 검색 조건

| 요소 | 타입 | 설명 |
|---|---|---|
| 이름 | Input | 부분 일치 |
| 사원번호 | Input | 부분 일치 |
| 부서 | Select | 전체 / 부서 목록 |
| 권한 | Select | 전체 / ADMIN / EMPLOYEE |
| 휴가 승인 필요 여부 | Select | 전체 / 필요 / 불필요 |
| 계정 상태 | Select | 전체 / 활성 / 비활성 (기본: 활성) |
| 검색 버튼 | Button | 검색 실행 |
| 신규 등록 버튼 | Button | 사원 등록 모달 열기 |

## 4. 목록 구성

이름 오름차순으로 표시한다.

| 컬럼 | 설명 |
|---|---|
| 이름 | 사원 이름 |
| 사원번호 | 사원번호 |
| 부서 | 소속 부서. 없으면 `-` |
| 권한 | ADMIN / EMPLOYEE |
| 휴가 승인 | 필요 / 불필요 |
| 계정 상태 | 활성 / 비활성 |
| 등록일 | 계정 생성일 |
| 상세보기 | `/admin/users/:id`로 이동 |

## 5. 동작 명세

### 사원 조회

1. 화면 진입 시 기본 조건으로 사원 목록을 조회한다.
2. 검색 조건 입력 후 검색 버튼을 클릭한다.
3. 사원 목록 API를 호출한다.
4. 결과를 목록에 표시한다. 페이지네이션과 검색 조건 유지는 03 공통 규칙을 따른다.

### 신규 사원 등록

1. 신규 등록 버튼 클릭
2. 사원 등록 모달 표시

   | 항목 | 타입 | 필수 | 설명 |
   |---|---|---|---|
   | 이름 | Input | O | 최대 100자 |
   | 사원번호 | Input | O | 숫자만, 최대 50자리, 중복 불가 |
   | 초기 비밀번호 | Password Input | O | FR-AUTH-003 비밀번호 규칙 적용 |
   | 부서 | Select | X | 부서 목록 |
   | 권한 | Select | O | ADMIN / EMPLOYEE (기본 EMPLOYEE) |
   | 휴가 승인 필요 여부 | Switch | O | 기본: 필요 |

3. 등록 버튼 클릭
4. 입력값 검증
5. 사원 등록 API 호출
6. 성공 시 모달을 닫고 토스트 "사원이 등록되었습니다. 최초 로그인 시 비밀번호를 변경해야 합니다."를 표시한 뒤 목록 갱신

부여 연차는 등록 후 사원 상세(SCR-007)에서 입력한다.

## 6. 유효성 검증

| 조건 | 메시지 |
|---|---|
| 이름 필수 | 이름을 입력해주세요. |
| 사원번호 필수 | 사원번호를 입력해주세요. |
| 사원번호 숫자만 | 사원번호는 숫자로 입력해주세요. |
| 초기 비밀번호 필수·규칙 | 비밀번호는 8자 이상, 영문과 숫자를 포함해야 합니다. |
| 권한은 ADMIN / EMPLOYEE만 | (Select로 제한) |
| 부서가 지정된 경우 존재하는 부서 | (Select로 제한, 서버 400 INVALID_DEPARTMENT) |

## 7. API

| 기능 | API |
|---|---|
| 사원 목록 | `GET /admin/users` (API-USER-001) |
| 사원 등록 | `POST /admin/users` (API-USER-002) |
| 부서 목록 | `GET /departments` (API-DEPT-001) |

## 8. 권한 및 예외

- ADMIN만 접근할 수 있으며 서버에서도 검증한다.

| 응답 | 처리 |
|---|---|
| 409 DUPLICATE_EMP_ID | 사원번호 필드 아래 "이미 사용 중인 사원번호입니다." |
| 400 INVALID_DEPARTMENT | 부서 목록을 다시 조회하고 "부서를 다시 선택해주세요." |

## 9. 상태 처리

공통 규칙(03 Common UI Rules)을 따른다.

- Empty: 조건에 맞는 사원이 없습니다.
- 부서 목록 조회 실패: 부서 Select를 비활성화하고 "부서 목록을 불러오지 못했습니다." 표시

## 10. 완료 조건

- 사원 목록 조회와 검색이 가능하다.
- 초기 비밀번호를 포함해 신규 사원을 등록할 수 있다.
- 중복 사원번호 등록이 방지된다.
- 관리자가 아닌 사용자의 접근이 차단된다.
