# SCR-009: 비밀번호 변경

## 1. 기본 정보

| 항목 | 내용 |
|---|---|
| Screen ID | SCR-009 |
| 화면명 | 비밀번호 변경 |
| URL | /password |
| 접근 권한 | 공통 |
| 관련 요구사항 | FR-AUTH-001, FR-AUTH-003 |

## 2. 화면 목적

사용자가 비밀번호를 변경한다.
최초 로그인 사용자(`mustChangePassword = true`)는 이 화면에서 비밀번호를 변경해야 다른 화면을 사용할 수 있다.

## 3. 화면 구성

| 요소 | 타입 | 필수 | 설명 |
|---|---|---|---|
| 안내 문구 | Text | - | 변경이 필요한 사용자에게만 "최초 로그인 시 비밀번호를 변경해야 합니다." 표시 |
| 현재 비밀번호 | Password Input | O | 관리자가 발급한 초기 비밀번호 또는 현재 비밀번호 |
| 새 비밀번호 | Password Input | O | FR-AUTH-003 규칙 |
| 새 비밀번호 확인 | Password Input | O | 새 비밀번호와 일치 |
| 변경 버튼 | Button | - | 변경 실행 |
| 취소 버튼 | Button | - | 이전 화면으로 이동. 변경이 필요한 사용자에게는 표시하지 않음 |

- 변경이 필요한 사용자에게는 전역 메뉴 중 로그아웃만 노출한다.

## 4. 동작 명세

1. 현재 비밀번호, 새 비밀번호, 새 비밀번호 확인을 입력한다.
2. 변경 버튼을 클릭한다.
3. 입력값을 검증한다.
4. 비밀번호 변경 API를 호출한다.
5. 성공 시 사용자 정보의 `mustChangePassword`를 false로 갱신하고 토스트 "비밀번호가 변경되었습니다."를 표시한 뒤 `/dashboard`로 이동한다.

## 5. 유효성 검증

| 조건 | 메시지 |
|---|---|
| 모든 항목 필수 | 비밀번호를 입력해주세요. |
| 새 비밀번호 규칙(FR-AUTH-003) | 비밀번호는 8자 이상, 영문과 숫자를 포함해야 합니다. |
| 새 비밀번호 72바이트 이하 | 비밀번호는 72바이트 이내로 입력해주세요. |
| 새 비밀번호 ≠ 현재 비밀번호 | 현재 비밀번호와 다른 비밀번호를 입력해주세요. |
| 새 비밀번호 확인 일치 | 새 비밀번호가 일치하지 않습니다. |

## 6. API

- `PATCH /api/v1/auth/password` (API-AUTH-005)

## 7. 예외 처리

| 응답 | 처리 |
|---|---|
| 400 INVALID_CURRENT_PASSWORD | 현재 비밀번호 필드 아래 "현재 비밀번호가 올바르지 않습니다." |
| 400 PASSWORD_POLICY_VIOLATION | 새 비밀번호 필드 아래 서버 메시지 표시 |

그 밖의 처리는 03 Common UI Rules를 따른다.

## 8. 완료 조건

- 비밀번호를 변경할 수 있다.
- 최초 로그인 사용자는 비밀번호를 변경하기 전에 다른 화면을 사용할 수 없다.
- 변경 후 대시보드로 이동한다.
