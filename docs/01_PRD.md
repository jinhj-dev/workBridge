# 01. PRD — workBridge

## 1. 프로젝트 개요

workBridge는 중소기업을 대상으로 하는
근태 및 휴가 관리 웹 애플리케이션이다.

직원의 출퇴근 기록, 휴가 신청, 승인 및
관리자 관리를 하나의 시스템에서 제공한다.

## 2. 프로젝트 배경

기존에는 Excel 및 수작업으로 근태와 휴가를 관리하여
다음과 같은 문제가 발생한다.

- 근태 데이터의 수동 관리
- 휴가 신청 및 승인 과정의 비효율성
- 근태 데이터의 조회 및 집계 어려움
- 데이터 중복 및 관리 오류

## 3. 프로젝트 목적

- 근태 및 휴가 관리 업무의 효율화
- 신청 및 승인 프로세스의 시스템화
- 데이터 관리의 정확성 향상

## 4. 사용자

- 일반 직원
- 관리자

## 5. 주요 기능

- 로그인, 로그아웃 및 비밀번호 변경
- 출근 및 퇴근 등록
- 근태 이력 조회 및 관리자 근태 수정
- 휴가 신청 및 취소
- 휴가 승인 및 반려
- 사원 관리(계정 상태, 승인 정책, 부여 연차)
- 관리자 대시보드

## 6. 개발 범위

### 구현 대상
- 웹 애플리케이션, 웹앱 애플리케이션
- REST API
- 사용자 인증 및 권한 관리
- 근태 및 휴가 관리

### 구현 제외
- 급여 계산
- GPS 기반 출퇴근
- 모바일 네이티브 앱
- 외부 회계 시스템 연동

## 7. 성공 기준

- 직원이 출퇴근 기록을 등록할 수 있다.
- 직원이 휴가 신청을 할 수 있다.
- 휴가 승인자가 본인에게 할당된 휴가를 승인 및 반려할 수 있고, 관리자는 모든 승인 대기 휴가를 대리 처리할 수 있다.
- 권한에 따라 데이터 접근이 제한된다.
- 주요 기능에 대한 자동화 테스트가 존재한다.
- 실제 환경에 배포되어 접근 가능하다.

## 8. 개발 제약사항

- 개발 기간: 1개월
- 개발 인원: 1명
- 개발 도구: Claude Code
- Frontend: Next.js
- Backend: NestJS
- Database: PostgreSQL
